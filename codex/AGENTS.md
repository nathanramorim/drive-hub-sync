# drive-hub-sync no Codex

Instalação: copie `skills/drive-hub` para `.agents/skills/drive-hub` (o Codex lê skills de `.agents/skills`) e acrescente este trecho ao `AGENTS.md` do projeto.

Fonte consultada (2026-11-16): documentação oficial do Codex, https://developers.openai.com/codex/skills e https://developers.openai.com/codex/guides/agents-md.

## Hub de documentação no Drive
Para configurar, subir ou descer o hub do Drive, use a skill `drive-hub` (`.agents/skills/drive-hub/SKILL.md`) e siga os procedimentos Configurar, Sincronizar e Descer dela. As regras vivem só na skill.
