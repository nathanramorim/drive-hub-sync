📁 drive-hub-sync

Um ajudante que organiza a documentação dos seus projetos no seu Google Drive. Você só diz onde guardar, e ele cuida do resto.

O que é Como funciona Como instalar Como usar Segurança Dúvidas

O que é isso?

Todo projeto tem documentos: histórico de novidades, desenhos de como as coisas funcionam, textos do site e materiais de divulgação. Com o tempo eles se espalham e ficam difíceis de achar.

O drive-hub-sync cria uma pasta bem arrumada no seu Google Drive para cada projeto e mantém tudo atualizado. É como ter um arquivo organizado que se atualiza quando você pede.

🗂️

Pasta organizada

Cria um conjunto fixo de pastas numeradas, igual para todos os seus projetos.

🔄

Atualiza quando você pede

Depois de uma novidade no projeto, um comando coloca o resumo no lugar certo.

🔒

Sem código

Só vão textos, imagens e vídeos. O código do projeto nunca é copiado.

Como as pastas ficam

Dentro da pasta do Drive que você escolher, ele cria uma pasta com o nome do projeto:

Meu Drive/
└── Projetos/
    └── meu-projeto/
        ├── 00-LEIA-ME-INDICE-GERAL.md
        ├── 01-Documentacao-Base-IA/
        ├── 02-Arquitetura-e-Diagramas/
        ├── 03-Releases-e-Roadmap/
        └── 04-Marketing-e-Landing-Page/
  • 00: índice, um "sumário" para achar tudo.
  • 01: resumo do projeto escrito para uma IA entender rápido.
  • 02: desenhos e decisões de como o projeto é montado.
  • 03: histórico de novidades e o que vem pela frente.
  • 04: textos do site, imagens e ideias de posts.

Como instalar

Antes, você precisa de duas coisas:

  1. O programa Google Drive para computador instalado e com login feito. Assim a pasta do Drive aparece no seu computador.
  2. O Claude Code o Codex ou o agy (Antigravity), o programa de IA que você usa.

Escolha o que você usa:

Instalando no Claude Code

  1. Abra o Claude Code e cole este comando: 
    /plugin marketplace add nathanramorim/drive-hub-sync
  2. Agora instale o plugin: 
    /plugin install drive-hub-sync@drive-hub-sync
  3. Pronto! Digite /drive-setup para ver se aparece. Se aparecer, está instalado.

Instalando no agy (Antigravity)

No agy, o plugin funciona como uma "habilidade": você copia uma pasta para dentro do seu projeto.

  1. Dentro do seu projeto, abra o terminal e baixe o plugin, depois copie a pasta skills/drive-hub para .agents/skills: 
    git clone https://github.com/nathanramorim/drive-hub-sync.git
mkdir -p .agents/skills
cp -R drive-hub-sync/skills/drive-hub .agents/skills/
  2. Abra o agy no projeto e escreva em português normal, sem comandos especiais: 
    Configure o hub do Drive para este projeto
Os comandos /drive-setup e /drive-sync são do Claude. No agy você pede com palavras normais, como no exemplo acima.

Como usar

1. Configurar (só uma vez por projeto)

Peça para configurar. No Claude, digite /drive-setup. No agy, escreva "Configure o hub do Drive para este projeto". Ele vai perguntar:

  • Em qual pasta do seu Drive guardar? (exemplo: Meu Drive/Projetos)
  • Qual é o nome do projeto?
  • De quais pastas do projeto ele deve ler os documentos?

Ele mostra o que vai criar e espera você dizer "sim" antes de mexer em qualquer coisa.

2. Atualizar (sempre que houver novidade)

Fez uma nova versão, mudou algo importante ou atualizou o site? Peça para sincronizar. No Claude, digite /drive-sync. No agy, escreva "Sincronize o projeto com o Drive".

Você também pode escolher só uma parte:

  • /drive-sync release: só as novidades da versão
  • /drive-sync arquitetura: só os desenhos e decisões
  • /drive-sync marketing: só textos e imagens de divulgação

Antes de gravar, ele mostra um resumo e pede sua confirmação.

É seguro?

  • ✔ Nunca copia código do seu projeto, nem senhas, nem arquivos secretos.
  • ✔ Só escreve dentro da pasta do projeto no Drive. Não mexe em outras pastas suas.
  • ✔ Sempre pergunta antes de gravar.
  • ✔ Seu caminho pessoal fica num arquivo .drive-hub.json que não vai para o git, então não vaza se você compartilhar o projeto.

Dúvidas comuns

Não acho a pasta do Google Drive no computador.

Instale o "Google Drive para computador" e entre na sua conta. No Mac, a pasta fica em Biblioteca/CloudStorage; o plugin procura por ela sozinho. No Windows e no Linux ele vai pedir que você informe o caminho.

Posso usar com vários projetos?

Pode. Rode a configuração uma vez em cada projeto. Todos ficam com o mesmo padrão de pastas.

Posso mudar o nome das pastas numeradas?

Pode. Os nomes são só um ponto de partida. Edite o arquivo .drive-hub.json ou peça para a IA ajustar.

Meu amigo usa outro Drive. Funciona?

Funciona. O destino é sempre escolhido por quem instala, então cada pessoa usa o seu próprio Drive.
