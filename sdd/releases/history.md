# Release Notes — drive-hub-sync

Este arquivo registra o histórico de entregas de produto deste projeto.

## Entregas

### 0.2.0 (2026-11-16)
- **Descer do Drive:** `/drive-pull` traz as edições do hub para o projeto, mostra o diff e, se os dois lados mudaram, pergunta qual manter.
- **Grafo de documentos:** cada documento do hub tem links para os relacionados; abra no Obsidian e veja o grafo.
- **Codex:** o plugin agora funciona também no Codex, com a mesma skill.
